# SKHY 上市后历史分析设计

## 目标

将 SK hynix 的 Nasdaq ADR `SKHY` 纳入 skill 的正式支持标的，并确保个股报告只使用其 2026-07-10 起的美股上市后数据；数据不足的模块必须明确说明限制，不得用韩国原股 `000660.KS` 历史拼接或填充。

## 已确认的边界

- 个股代码固定为 `SKHY`。
- 历史行情、技术指标、52 周指标、收益率和回测仅使用 `2026-07-10`（含）之后的行情。
- `000660.KS` 仅可在报告中作为韩国原股代码说明，不能参与 `SKHY` 的数值计算、图表、评分或历史补齐。
- 数据不足可以接受，但必须以可解释的提示替代空白、异常值或看似完整的长期指标。
- 行业资料和公司画像可使用 SK hynix 的公开披露；行情和基础财务仍优先来自已登录的 `panda_data`。

## 方案

### 标的元数据

在集中配置中为 `SKHY` 定义美国市场、上市日 `2026-07-10`、`post_listing_only` 历史策略，以及 ADR/韩国原股关系的展示说明。行业刷新白名单和命令行支持列表同时加入 `SKHY`。

### 历史数据边界

获取行情后立即按上市日过滤，后续技术指标、图表、评分和回测只接收该过滤后的 DataFrame。任何数据源返回的上市前记录都不可信任，不得透传到报告。

### 可用性规则

| 模块 | 最小数据要求 | 不满足时的行为 |
| --- | --- | --- |
| 短期技术指标 | 各指标自身的滚动窗口 | 显示“上市后交易日不足”，该指标为空 |
| 52 周位置、52 周收益 | 约 252 个交易日 | 不使用数据源的 52 周字段；显示不适用 |
| 长均线、年化波动率 | 对应窗口 | 不计算或显示不适用 |
| 历史回测 | 足以形成历史评分和对应前瞻观察期 | 返回结构化“上市后历史不足”，报告显示说明卡 |
| 财务、估值、分析师、事件 | 接口实际覆盖 | 保持现有缺失提示，不以韩国数据替代 |

报告需展示有效历史区间与交易日数量，提示文本应包含“SKHY 自 2026-07-10 在 Nasdaq 上市”。

### 行业画像与对标

新增 `SKHY` 的公司画像、CapEx 指引和 HBM/DRAM/NAND 技术定位。行业对标使用 `SKHY` 作为海力士可计算的美股 ADR 代码；韩国原股配置仅保留作说明性元数据。对标调用仍遵循 `panda_data` 实际覆盖，未返回的字段按现有缺失语义展示。

## 错误处理

- 若过滤后无行情，停止生成正式报告并提示 `SKHY` 上市后行情不可用。
- 若 `panda_data` 缺少某类基本面或事件数据，继续生成报告，但在相应模块显示数据源未覆盖。
- 不能因数据不足降低历史边界：禁止自动回退至 `000660.KS` 或其他代码。

## 测试与验收

自动化测试至少覆盖：

1. `SKHY` 在支持标的和行业对标中可识别。
2. 含上市前行的数据在进入计算前被过滤。
3. 少于 252 个交易日时不会采用 `pv_metric` 的 52 周高低或收益字段。
4. 历史不足的回测返回可渲染的原因，而不是缺键或异常。
5. 报告明确写出 Nasdaq 上市日期、有效历史区间和数据不足提示。

验收时以一次已登录的 `SKHY` 实际运行作为数据覆盖检查；它可以缺少某些接口数据，但不得因缺失中断、泄露凭据或生成韩国历史拼接结果。
